# Privacy Policy

**1/f Yuragi** — Last updated: 2026-06-04

## Overview

1/f Yuragi is a desktop overlay application. It does not collect, transmit, or store any personal data.

## Data Collection

This application collects **no data whatsoever**.

- No personal information
- No usage analytics or telemetry
- No crash reports
- No network connections
- No cookies or tracking

## Local Files

The application stores the following files **locally on your device only**, in the same folder as the executable:

| File | Purpose |
|---|---|
| `config.json` | Your settings (grass layout, wind, mouse fade, etc.) |
| `saves/` | Saved presets (grass and environment) |

These files never leave your device. They are not uploaded, synced, or shared.

## Network Access

This application makes **zero network connections**. It operates entirely offline.

## Third-Party Services

This application uses no third-party services, SDKs, or APIs.

## Children's Privacy

This application does not collect any data from anyone, including children.

## Changes to This Policy

If this policy changes, the updated version will be published in this repository.
