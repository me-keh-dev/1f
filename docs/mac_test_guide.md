# macOS テストガイド

## 環境準備

```bash
# Python 3.9以上
python3 --version

# リポジトリ取得
git clone https://github.com/me-keh-dev/1f.git
cd 1f

# 依存インストール
pip3 install PyQt5 pyobjc-core pyobjc-framework-Cocoa
```

## テスト1: 起動するか

```bash
python3 main.py
```

- [ ] エラーなく起動するか
- [ ] Dockの上に草が表示されるか（位置がずれていないか）
- [ ] システムトレイ（メニューバー）に緑のアイコンが出るか

## テスト2: クリック透過

- [ ] 草の上をクリックしても、下のアプリ（Finder等）を操作できるか
- [ ] 草がマウス操作の邪魔にならないか

## テスト3: 1/fゆらぎ・風

- [ ] 草が揺れているか
- [ ] 風が左から右に波のように伝播しているか
- [ ] 突風（たまに強く吹く）が感じられるか

## テスト4: マウス近接透過

- [ ] マウスを草に近づけると草が薄くなるか
- [ ] マウスを離すと元に戻るか

## テスト5: 設定画面

- [ ] トレイアイコン右クリック → 「設定」で設定画面が開くか
- [ ] スライダーを動かして「適用」で反映されるか
- [ ] 「再生成」で草が変わるか

## テスト6: ホットキー

- [ ] Cmd+Ctrl+Shift+W で草の表示/非表示が切り替わるか
  - ※ 動かない可能性あり（pyobjcのイベント監視が必要）
  - その場合、トレイメニューの「表示切替」で代替できるか

## テスト7: 保存・読み込み

- [ ] 設定画面で「草を保存」→ saves/grass/ にファイルが作られるか
- [ ] 「環境を保存」→ saves/env/ にファイルが作られるか
- [ ] アプリ再起動後、前回の草が復元されるか

## 問題が出た場合

エラーメッセージをそのままコピーして共有してください：

```bash
# エラー詳細を見るにはターミナルから実行
python3 main.py 2>&1 | tee test_log.txt
```

## 確認済みの既知の制約

- macOS版はまだ未テスト。platform_mac.py のPyObjC連携が正しく動くか要確認
- ホットキーはmacOSの権限（アクセシビリティ）許可が必要な可能性あり
- Retinaディスプレイでの表示サイズが適切か要確認
